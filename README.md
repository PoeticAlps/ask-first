# ask-first — 先问再做

一个 AI 编程助手的工作流 skill：在**新项目或模糊需求**时，先通过少量多轮提问收集齐上下文，汇总确认后再动手；指令明确时则不打扰、直接执行。

## 解决什么问题

- AI 拿到模糊想法就开写，产出方向错误，返工成本高 → **先问 2-3 轮（每轮 3 问）再执行**
- 反过来，简单任务也被反复追问，体验糟糕 → **明确指令和琐碎任务直接触发不进入提问**

## 安装

把本目录放入支持 skill 的客户端的 skills 目录（如 `~/.zcode/skills/`、`.claude/skills/`），或在插件市场中安装即可，无其他依赖。

## 使用

无需手动调用。skill 根据用户指令自动判断：

| 输入类型 | 行为 |
|---|---|
| "我想做一个网站" | 触发提问：目标 / 技术栈 / 范围，每轮 3 问 |
| "帮我把标题改成首页" | 不触发，直接改 |

用户回答用句号（。）分隔各点即可；回答中夹带的新问题会被先回答再继续提问。
